# SQL---Market-Research-Analytics-Customer-Insights-using-SQL-Server
An end-to-end SQL analytics project designed to analyse market research survey data and derive meaningful business insights. The project uses a synthetic dataset containing 500,000 records to explore customer satisfaction, survey participation, industry performance, and research project financials.

### Key Analysis
- Analysed survey responses and customer satisfaction.
- Evaluated industry-wise trends and survey performance.
- Calculated Net Promoter Score (NPS).
- Explored project budgets and contract revenue.
- Applied data validation, aggregations, CTEs, subqueries, and window functions.

### Key Outcomes
- Developed a structured SQL analytics workflow.
- Identified customer feedback and satisfaction patterns.
- Generated industry and project-level insights.
- Strengthened practical SQL querying and analytical skills.

### Tools & Technologies
SQL Server | SQL | SQL Server Management Studio (SSMS)

### Dataset
500,000 synthetic records created for learning and portfolio demonstration. The data does not represent actual customers or business transactions.
